# Product Catalog App

## Overview
The Product Catalog App is a web application that allows users to browse a catalog of products, add them to a shopping cart, and complete their purchases. The application features a user-friendly interface and supports various payment methods.

## Project Structure
```
product-catalog-app
├── src
│   ├── index.html        # Main HTML document for the product catalog
│   ├── styles
│   │   └── style.css     # CSS styles for layout and design
│   ├── scripts
│   │   └── app.js        # JavaScript for handling application functionality
├── assets
│   ├── images            # Directory for product images
│   └── icons             # Directory for application icons
├── README.md             # Documentation for the project
```

## Features
- **Product Display**: View a list of available products with images and descriptions.
- **Shopping Cart**: Add products to the cart, adjust quantities, and remove items.
- **Additional Notes**: Provide special instructions or notes for each order.
- **Payment Methods**: Select from various payment options.
- **Order Registration**: Users must register to complete their orders.
- **WhatsApp Integration**: Send order details directly to the supplier via WhatsApp.

## Setup Instructions
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/product-catalog-app.git
   ```
2. Navigate to the project directory:
   ```
   cd product-catalog-app
   ```
3. Open `src/index.html` in a web browser to view the application.

## Usage Guidelines
- Browse through the product catalog and select items to add to your cart.
- Adjust quantities as needed and provide any additional notes.
- Choose your preferred payment method and complete the registration process.
- Upon submission, your order details will be sent to the supplier via WhatsApp.
